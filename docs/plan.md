# План об'єднання WorkoutTitan і Record

## Рішення

| Питання | Рішення |
| --- | --- |
| Стек | Expo SDK 58, React Native, TypeScript. Swift не використовується: у жодному з двох репозиторіїв його немає |
| Платформа | Спершу Android. iOS пізніше: потрібні iPhone для тестів і Apple Developer акаунт |
| Назва | Record |
| Ідентифікатор | `com.netherm3.record`. Можна змінити до першої публікації в магазині, потім ні |
| Скіни | І теми інтерфейсу, і косметика аватара та табору |
| Монетизація | Без реклами. Преміум-підписка 1,5 $ на місяць із косметикою, плюс донати з фіксованими сумами |
| Дані | Лише на телефоні. Схема готується до синхронізації в майбутньому |
| Функції Titan | Кухня, GPS-кардіо та його журнал вправ не переносяться |
| Таби | Головна, Тренування, Тіло, Досягнення, Налаштування. «Підтримка автора» відкривається з налаштувань |

## Етапи

| № | Етап | Стан |
| --- | --- | --- |
| 0 | Інструменти: TypeScript, ESLint, Jest | Готово |
| 1 | Каркас: таби, скіни, мови, шрифти з кирилицею | Готово |
| 2 | Ядро Record: числова модель, формули, конвертер старих записів | Далі |
| 3 | Локальна база даних: схема, міграції, CRUD | |
| 4 | Екрани: Головна, запис результату, Тренування, Тіло, Досягнення | |
| 5 | Косметика: вибір і збереження, відкриття за досягнення, преміум-набір | |
| 6 | Налаштування: одиниці, вправи, експорт та імпорт, перенесення записів із Firestore | |
| 7 | Покупки: підписка, донати, екран «Підтримка автора» | |
| 8 | Переклад і полірування | |
| 9 | Реліз: іконка, скріншоти, політика приватності, подача в магазин | |

## Коли етап готовий

- `npm run check` проходить: типи, лінтер без жодного попередження, тести.
- `npm run bundle` збирає бандл без помилок.
- Нові екрани беруть кольори й шрифти лише зі скіна і мають рядки в обох мовах.
- Перевірено на телефоні: це робить власник, в Expo Go або в збірці.

## Що лишилося з попереднього

- Іконка і заставка досі стандартні від Expo. Це етап 9.
- Арт WorkoutTitan (близько 144 МБ) лежить у репозиторії, але в збірку зараз входять лише чотири шари сцени табору. Решта повернеться на етапі 5, уже відібрана й стиснена.
- Тести запускаються як Android. Коли з'явиться iOS, треба додати другий прогін.
