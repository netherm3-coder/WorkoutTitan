# План об'єднання WorkoutTitan і Record

## Рішення

| Питання | Рішення |
| --- | --- |
| Стек | Expo SDK 58, React Native, TypeScript. Swift не використовується: у жодному з двох репозиторіїв його немає |
| Платформа | Спершу Android. iOS пізніше: потрібні iPhone для тестів і Apple Developer акаунт |
| Назва | Record |
| Ідентифікатор | `com.netherm3.record`. Можна змінити до першої публікації в магазині, потім ні |
| Скіни | І теми інтерфейсу, і косметика аватара та табору |
| Монетизація | Без реклами. Преміум-підписка 1,5 $ на місяць із косметикою, плюс донати з фіксованими сумами |
| Дані | Лише на телефоні. Схема готується до синхронізації в майбутньому |
| Функції Titan | Кухня, GPS-кардіо та його журнал вправ не переносяться |
| Таби | Головна, Тренування, Тіло, Досягнення, Налаштування. «Підтримка автора» відкривається з налаштувань |

## Коли етап готовий

- `npm run check` проходить: типи, лінтер без жодного попередження, тести.
- `npm run bundle` збирає бандл без помилок.
- Нові екрани беруть кольори й шрифти лише зі скіна і мають рядки в обох мовах.
- Перевірено на телефоні: це робить власник, в Expo Go або в збірці.

## Що лишилося з попереднього

- Записувати можна лише сім вбудованих вправ. Власних вправ, цілей і лічильників стажу й тверезості на екранах ще немає: це третя частина етапу 4. Досягнення тверезості не показуються, доки лічильник не має дати початку.
- Заміри тіла мають вісім вбудованих частин; власних і фото прогресу ще немає.
- Час вводиться двома полями, хвилини і секунди, бо цифрова клавіатура Android не має двокрапки. Години окремо не вводяться: 1:45:30 це 105 хвилин 30 секунд.
- База не перевірена на справжньому телефоні: тести ганяють її на SQLite в Node, а нативну частину `expo-sqlite` замінюють. Перевіряє власник: у налаштуваннях унизу має бути «Записів на телефоні: 0», і рядок має лишатися після перезапуску.
- Дані, внесені в Expo Go, окрема збірка не побачить. Доки немає експорту (етап 6), справжні записи в Expo Go вести не варто.
- Два приватні заміри з Record вбудованими не зроблено. Таблиця замірів приймає будь-яку назву частини тіла, тож власні заміри з'являться на етапі 6 без зміни схеми.
- Конвертер старих записів перевірений на згенерованих історіях у форматах Record, але не на справжніх даних. Для цього потрібен CSV з «Експорт рекордів» або доступ до Firestore; перевірка на етапі 6.
- Відкрите питання для етапу 6: результат власної вправи з числом і часом (`50 (0:41.2)`) зараз порівнюється за числом. Якщо головний час, вправу треба переносити як «дистанція і час».
- Іконка і заставка досі стандартні від Expo. Це етап 9.
- Арт WorkoutTitan (близько 144 МБ) лежить у репозиторії, але в збірку зараз входять лише чотири шари сцени табору. Решта повернеться на етапі 5, уже відібрана й стиснена.
- Тести запускаються як Android. Коли з'явиться iOS, треба додати другий прогін.
